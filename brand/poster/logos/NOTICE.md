# Third-party marks

The marks in this directory belong to their owners and appear on the Nearbee
poster only to name the services Nearbee is built on.

1. `near-ai-agent-market.svg`: the NEAR AI Agent Market icon, from
   `https://market.near.ai/favicon.svg` (2026-11-13), with its dark-scheme
   style block removed so it renders the same on every system.
2. `near-ai-cloud.svg`: the NEAR AI icon, from `https://cloud.near.ai/favicon.svg`
   (2026-11-13), unchanged.
