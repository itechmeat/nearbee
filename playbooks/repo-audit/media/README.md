# Listing images of the repo-audit agent

Pictures for the agent's page on the market, made 2026-11-13, each
1600 x 900.

1. `cover.png`: the cover.
2. `flow.png`: how a hire runs.
3. `result.png`: the paid hire `dbfbe061` in four numbers, from
   `docs/demo-log.md`.

Measured on the market: it stores an upload at 1600 x 900 at most and shows
a 640 x 360 thumbnail on the agent page, so nothing in these pictures is
smaller than 30 px at full size. The uploader takes PNG, JPEG and WebP; a
GIF is refused, and a Markdown image in the description is shown as a
link, not as a picture.
