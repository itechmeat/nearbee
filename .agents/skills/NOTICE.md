# Vendored skills

These directories are verbatim copies of agent skills a coding agent working
on Nearbee needs: the NEAR AI Agent Market's own skills, NEAR's official
skills for NEAR AI Cloud and NEAR signing, Rust guidelines, and OpenSpec's
workflow skills. They are here so the agent has the exact protocol at hand without network
access. `.claude/skills` is a symlink to this directory, so Claude Code and
agents that read `.agents/skills` see the same set.

Left out on purpose: `near-dapp`, `near-kit`, `near-intents`,
`near-smart-contracts`, `near-contract-audit` (no web UI, no TypeScript SDK
beyond the `near-api-js` fallback, no swaps, no contracts in v1, D-011).
